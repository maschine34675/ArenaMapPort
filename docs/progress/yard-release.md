- **Contradictions between the surveys and how the plan resolved them.**
  1. **Grass.** S4 concluded "nothing needs porting" from the scene's three empty objects; S3 deferred it; S5 found the 10,132-clump external file and the full runtime chain. S5 wins (it read the instance data and the components); the plan gives grass its own gate (item 22) and a conditional project (item 23) instead of Iceberg's one-line "not ported".
  2. **Duplicate scene copies.** S0 and S4 left content equality open (S4 inferred from file sizes only); S1, S2 and S3 byte-compared the level files and found them identical. Resolved as settled; the plan keeps the first-listed picks and pins the indices (item 7).
  3. **Locale name.** S4 took "Block" from `markers.json` only and called the locale unread; S1 read Arena's locale tables (key and Name row of the location id). S1 wins; "Arena: Block" is the default, flagged for the user.
  4. **Official description.** S4 was unsure Arena has one; S1 found rows in en, ge and ru under Arena's own id (the port `id_field` has none). The plan adds a `DESCRIPTION_KEYS` row.
  5. **Border cubes.** S0 and S1 counted 14 cubes in the package; S2 found 104 more in the excluded Scripts scene. The plan selects that root (item 4) and leaves `keep_level_borders` to the oracle: Arena's mask drops layer 29 on Bowl, Iceberg and Chop Shop too and those set it, so the mask is no reason (corrected in review; AirPit is the no-keep precedent).
  6. **Pocket rule.** Autoservice needed an explicit side rule (ratio 2.1); S2 measures 7.9 for Yard, so the tool's default rule applies and no rule is planned.
  7. **Rigidbody additions.** S0 counted "12 structural diffs", S1 and S2 count 13 added Rigidbodies and 11 material swaps. These are the same objects seen from different filters (4 + 9 Rigidbodies; 8 + 3 renderer material swaps); no conflict, cause of the Rigidbodies stays undetermined (content or extractor growth).
  8. **Flares.** S3 counts 0 active flares (exporter rule) yet 14 lights exist; the plan ships no flare package (Iceberg precedent) and pins the census, to be revisited only if the host shows lamp flares.
  9. **Native counts.** S3's numbers come from a scratch run with the two ballistic checks tolerated and without the 104 border cubes; the plan treats them as expectations to be re-read at item 5, not as pins.
