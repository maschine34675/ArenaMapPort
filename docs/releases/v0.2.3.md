# ArenaMapPort 0.2.3

Brings **Air Pit**, **Equator (Day/Night)** and **Bay5** from Escape from Tarkov: Arena to SPT.
The maps are those of 0.2.2. What changes: they now require an installed
**Escape from Tarkov: Arena**, and one weather error on Equator is fixed.

## Included

- **Air Pit:** an abandoned terminal hangar from Arena. It contains the furnished main hall
  with its four shops, the passport hall and the apron. Like Bay5 it has two normal server-time
  choices, a progressing day/night cycle and dynamic weather. Bot spawns, waves and PMC squads
  are included, and two gates (Air Pit North Gate and Air Pit South Gate) serve as extractions.
- **Equator** with a realistic daytime appearance and an optional neon midnight appearance.
- **Bay5** with normal time progression and dynamic weather.
- Imported geometry, materials, lighting, audio, collision and navigation, plus
  map-specific repairs.
- Optional DynamicMaps overview maps for all three maps, stored inside ArenaMapPort's own
  directory. Air Pit shows its ground floor; its upper spectator area is omitted.
- Original map descriptions in English, German and Russian, with English fallback.
- Per-room gunshot reverb on all three maps: shots ring differently in a big hall than in a
  small shop. The room data is invented, because neither EFT nor Arena provides gunshot
  reverb values; outdoors the shipped acoustics stay. It can be switched off per map under
  `Audio (<map key>)` / `RoomShotAcoustics` with `General/DeveloperMode` enabled (enable it
  and restart EFT).
- Spawn gates for mode plugins (added in 0.2.2): a mode plugin such as ArenaMode can keep the
  team spawn enclosures closed until the fight starts, as Arena does.

The maps are intended for **ArenaMode**, which is installed separately, and need
**Escape from Tarkov: Arena** to be installed (see below). No loot or scav raids
are provided. Tested with **SPT 4.1.6 / EFT 0.16.9.5-40743**; server compatibility is `~4.1.5`.
Optional DynamicMaps integration was tested with 1.2.1.

## Changes since 0.2.2

- **Requires an installed Escape from Tarkov: Arena.** Arena is sold separately from Escape from
  Tarkov, and these maps are built from its files, so they now need Arena on your PC, in the same
  way SPT needs an installed Escape from Tarkov. The server registers the Air Pit, Equator and Bay5
  locations, and the client loads their map files, only when an Arena installation is found and
  checked. It is found through the Battlestate Games launcher's entry for Arena in the Windows
  registry. It is checked by looking at the folder: it must contain the game executable and the
  launcher's file list (`ConsistencyInfo`), and every file in that list must exist with the listed
  size. That compares names and sizes only, reads no game data, takes about a second and sends
  nothing anywhere. Without a verified installation both components log the reason at Info; the
  server leaves the locations out of the location selection and the client does not load the map
  files. An Arena that is still updating or damaged does not pass until the launcher has
  repaired it. If your Arena installation has no launcher entry (a copied or moved folder), set its
  folder in `General / ArenaInstallPath` in `BepInEx/config/com.maschine.ArenaMapPort.cfg` (client)
  and in `SPT_Runtime/user/mods/ArenaMapPort/config/arena-install.json` (server). Both settings are
  checked exactly like the automatic path, and no setting turns the check off.
- **Weather fix after other maps.** Entering Equator after raids on other maps in the same game
  session (seen after Air Pit, Customs and Labyrinth) could write repeated weather, distant-shadow
  and ambient-highlight errors to the log: the ported map's cached sky was reused without being
  registered again with EFT's sky provider. It is registered again now. In one tested session
  (Equator, Labyrinth, Equator again, Customs, hideout) none of the three errors appeared.

## Known limitations

- No loot and no scav raids. Arena's match rules and respawns come from ArenaMode, which is
  installed separately. Fika compatibility has not been verified.
- The Arena check compares file names and sizes, not file contents. It is a good-faith
  installation check at SPT's own level, not copy protection.
- The per-room gunshot reverb uses invented room data (see Included).
- Air Pit's DynamicMaps overview shows the ground floor only; the upper spectator area is omitted.
- In an ordinary raid (no mode plugin) Air Pit's closed passport control stays the northern limit
  of the play area. A spawn-gate hold that nobody releases opens after five minutes with a warning.
- The weather fix covers the three errors named above; other messages in EFT's own log are unchanged.

## Installation

1. Install **Escape from Tarkov: Arena** with the Battlestate Games launcher if it is not installed
   yet. It is a separate purchase from Escape from Tarkov.
2. Close EFT and the SPT server.
3. Extract `maschine-ArenaMapPort-0.2.3.zip` into your SPT installation, merging `BepInEx`
   and `SPT_Runtime`. Install both the client and server components.
4. Start the SPT server, then EFT. The server log and the BepInEx log each show a line with the
   Arena installation that was found, or the reason none was.

The client folder is `BepInEx/plugins/maschine-ArenaMapPort`.
The server folder remains `SPT_Runtime/user/mods/ArenaMapPort`.

Arena is installed but not found? Set its folder in `General / ArenaInstallPath` (client,
`BepInEx/config/com.maschine.ArenaMapPort.cfg`) and in `SPT_Runtime/user/mods/ArenaMapPort/config/arena-install.json`
(server, `{"installPath": "D:\\Battlestate Games\\Escape from Tarkov Arena"}`, backslashes doubled);
both are checked like the automatic path.

**Upgrading from 0.2.2:** with EFT and the SPT server closed, extract the full ZIP over the
installation; this is the supported way to upgrade. Keep `BepInEx/config`.

**Upgrading from 0.2.1 or 0.2.0:** with EFT and the SPT server closed, extract the ZIP over the
installation (Air Pit's bundles changed in 0.2.2, so the two DLLs alone are not enough). The old
`BepInEx/plugins/maschine-ArenaMapPort/material-shaders.json` may be deleted. Keep `BepInEx/config`.

**Upgrading from 0.1.0:** with EFT and the SPT server closed, extract the ZIP over the
installation. Keep `BepInEx/config`; the configuration migrations run automatically.

**Upgrading a development build:** move the old `BepInEx/plugins/ArenaMapPort` directory
outside `BepInEx/plugins` before extracting. Keep your `BepInEx/config` settings.
Remove the retired `maschine-ArenaMapDebug.dll` if present, either directly in `plugins`
or inside `plugins/ArenaMapDebug`. The included README covers old database/DynamicMaps cleanup.

F12 exposes `NaturalEquatorNight` to use the natural appearance in the next Equator night raid.
`DeveloperMode` is an advanced setting and is off by default.
