# ArenaMapPort 0.2.0 (withdrawn)

> Withdrawn on 2026-10-16, the day it was built: the GitHub release, its tag and the Pixeldrain files were deleted
> (user decision; 0.2.1 is the first version published on the Forge). The links below no longer work. Kept as the
> record of what the package contained; [v0.2.1.md](v0.2.1.md) supersedes it.

Adds **Air Pit** to **Equator (Day/Night)** and **Bay5** for SPT, fixes the hideout
loading problem and a once-per-second freeze, and ships per-room gunshot reverb.

## Included

- **Air Pit (new):** an abandoned terminal hangar from Arena. It contains the furnished
  main hall with its four shops, the passport hall and the apron. Like Bay5 it has two
  normal server-time choices, a progressing day/night cycle and dynamic weather. Bot
  spawns, waves and PMC squads are included, and two gates (Air Pit North Gate and Air
  Pit South Gate) serve as extractions.
- Equator with a realistic daytime appearance and an optional neon midnight appearance.
  The map is unchanged in content.
- Bay5 with normal time progression and dynamic weather. The map is unchanged in content.
- Imported geometry, materials, lighting, audio, collision and navigation, plus
  map-specific repairs.
- Optional DynamicMaps overview maps for all three maps, stored inside ArenaMapPort's own
  directory. Air Pit shows its ground floor; its upper spectator area is omitted.
- Original map descriptions in English, German and Russian, with English fallback. This
  includes Air Pit.

The maps are intended for **ArenaMode**, which is installed separately. No loot or scav raids
are provided. Tested with **SPT 4.1.6 / EFT 0.16.9.5-40743**; server compatibility is `~4.1.5`.
Optional DynamicMaps integration was tested with 1.2.1.

## Changes since 0.1.0

- **Hideout loading fixed.** With 0.1.0 installed, the hideout never finished loading.
  One of the mod's patches sits on a generic game class that EFT also uses for the hideout,
  and since the Equator day/night profiles of 0.1.0 it ran there too and failed. The patch
  now acts only on the game type it was written for, and a failure inside it falls back to
  the original behavior. Related hardening: the two spatial-audio occlusion patches now run
  only on the mod's maps.
- **Once-per-second short freeze fixed on every ported map.** A scene-wide search ran every
  second (about 30 ms on the ported scenes). It now runs once per raid. On the test host the
  peak frame time dropped from 35 ms to 8.8-12 ms.
- **Ambience mix and bloom defaults are now the tuned values.** The Equator and Bay5 ambience
  gains changed, and Air Pit ships its tuned mix and bloom. An existing configuration that
  still holds the old default moves to the new value once; custom values are kept.
- **Per-room gunshot reverb on all three maps.** Shots ring differently in a big hall than in
  a small shop. The room data is invented, because neither EFT nor Arena provides gunshot
  reverb values: the room you stand in selects a made-up shoebox room model for the Meta XR
  Audio plugin. It is on by default; outdoors the shipped acoustics stay. It can be switched
  off per map under `Audio (<map key>)` / `RoomShotAcoustics` with `General/DeveloperMode`
  enabled (enable it and restart EFT); off restores the shipped gunshot acoustics.
- **Map selection.** The location markers sit at positions measured from Arena's original
  region screens, and ArenaMode's region selection shows Arena's original region artwork.
  Ordinary PMC/Scav selection and installations without ArenaMode keep EFT's original image.
- **Distribution.** The release is one ZIP (about 2.2 GB, 2.03 GiB) hosted on Pixeldrain, with a `.sha256`
  file. VirusTotal links are provided for the two DLLs only; the ZIP exceeds VirusTotal's
  file size limit.

## Installation

1. Close EFT and the SPT server.
2. Extract `maschine-ArenaMapPort-0.2.0.zip` into your SPT installation, merging `BepInEx`
   and `SPT_Runtime`. Install both the client and server components.
3. Start the SPT server, then EFT.

The client folder is `BepInEx/plugins/maschine-ArenaMapPort`.
The server folder remains `SPT_Runtime/user/mods/ArenaMapPort`.

**Upgrading from 0.1.0:** with EFT and the SPT server closed, extract the ZIP over the
installation. Keep `BepInEx/config`; the configuration migrations run automatically.

**Upgrading a development build:** move the old `BepInEx/plugins/ArenaMapPort` directory
outside `BepInEx/plugins` before extracting. Keep your `BepInEx/config` settings.
Remove the retired `maschine-ArenaMapDebug.dll` if present, either directly in `plugins`
or inside `plugins/ArenaMapDebug`. The included README covers old database/DynamicMaps cleanup.

F12 exposes `NaturalEquatorNight` to use the natural appearance in the next Equator night raid.
`DeveloperMode` is an advanced setting and is off by default.
