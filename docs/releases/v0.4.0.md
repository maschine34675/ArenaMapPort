# ArenaMapPort 0.4.0

Local release candidate, prepared on 2026-10-28. Not published; no release tag or download has been created.

## Changes since 0.3.0

- Original animated spectators on all four maps: 99 on Air Pit, Equator day/night and Bowl, 88 on Bay5.
  Fifteen appearances and original idle/cheering animations bring the galleries to life. The missing legacy
  face cloth uses Arena's current half-mask. The spectators are decoration and do not affect gameplay.
- Thirteen original fan recordings play from nearby spectators through the native spatial audio and room
  obstruction system. Up to three speakers can overlap, with no simultaneous duplicate voice family.
  Scav phrases are excluded. The crowd does not react to kills or round results yet.
- Shared spectator textures save approximately 440 MB compared with the development layout, with identical
  image bytes. Missing, damaged or mismatched map/texture packages are detected instead of rendering the
  wrong spectator appearance.
- Gate and door sounds play when a mode plugin releases held spawn gates on all four maps.
  Exit lamps on Equator and Air Pit switch with those gates.
- Original TV screens can show a mode's timer, team scores and alive counts through the optional
  ScoreMonitors integration. They remain unchanged without a mode plugin using the interface.
- Puddle footsteps restored on Equator, Air Pit and Bowl, in addition to Bay5.
- Four Equator/Bay5 spawn positions moved slightly inboard from the navigation edge.
- Suppress a redundant map-error dialog after EFT has already explained the same failed load.

## Requirements and compatibility

SPT 4.1.6 / EFT 0.16.9.5-40743; the server declares `~4.1.5`. Both client and server components are required.
An installed Escape from Tarkov: Arena is required on the machines loading/registering the maps. The existing
bundle keys target Arena **0.6.1.0.48206** and were also verified with **0.6.0.0.47752**. An Arena update that
changes the sampled map resources needs updated keys. This requirement is not copy protection.

ArenaMode supplies match rules and respawns separately. DynamicMaps and SAIN are optional. Fika compatibility
has not been verified. No loot or scav raids are included.

## Installation and upgrade

Close EFT and the SPT server. Extract the complete ZIP into the SPT root, merging `BepInEx` and `SPT_Runtime`,
then restart the server and game. Install both components from this package; a DLL-only update is insufficient.
Upgrading the published 0.3.0 package needs no spectator cleanup because that release contained no spectators.

Development installations with the earlier per-map PNG files can retain those unused copies safely, but they
consume extra disk space. After installing and verifying this complete package, remove only the `.png` files
directly inside `BepInEx/plugins/maschine-ArenaMapPort/spectators/arena_airpit`, `arena_equator`, `arena_bay5`
and `arena_bowl`. Keep each `spectator.json.gz` and the complete `spectators/shared` folder. The development
deployment script provides `-RemoveLegacySpectatorTextures` (dry run first, then `-Confirm`) and refuses
unknown/changed files or incomplete replacements. It never removes other plugins or settings.
