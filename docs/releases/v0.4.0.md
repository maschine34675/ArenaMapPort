# ArenaMapPort 0.4.0

29 October 2026. Original animated crowds, spatial spectator calls, gate sounds and mode-driven score screens
for Equator, Bay5, Air Pit and Bowl.

## Changes since 0.3.0

- Original animated spectators on all four maps: 99 on Air Pit, Equator day/night and Bowl, 88 on Bay5.
  Fifteen appearances and original idle/cheering animations run at staggered intervals. The missing legacy
  face cloth uses Arena's current half-mask. The spectators are decoration and do not affect gameplay.
- Thirteen original fan recordings play from nearby spectators through native spatial audio and room
  obstruction. Up to two speakers overlap, with 1.6-3.2 seconds between starts, waiting while both slots
  are occupied. Speakers and voice families do not duplicate. Scav phrases are excluded; kill and
  round-result reactions are not implemented.
- Shared spectator textures save approximately 440 MB compared with the development layout, with identical
  image bytes. Integrity checks detect missing, damaged or mismatched map/texture packages.
- Gate and door sounds play when a mode plugin releases held spawn gates on all four maps.
  Exit lamps on Equator and Air Pit switch with those gates.
- Original TV screens can show a mode's timer, team scores and alive counts through the optional
  ScoreMonitors integration. They remain unchanged without a mode plugin using the interface.
- Puddle footsteps are restored on Equator, Air Pit and Bowl, in addition to Bay5.
- Four Equator/Bay5 spawn positions moved slightly inboard from the navigation edge.
- A redundant map-error dialog is suppressed after EFT already explained the same failed load.
- Late collisions from remaining Arena props after map teardown no longer request the unloaded native
  sound bundle. The owned-scene guard preserves the collision timer and ordinary-map behavior.
- Spectator output readback runs only with startup-enabled DeveloperMode. The live developer-only
  `Audio diagnostics/SpectatorCalls` switch isolates crowd calls for hearing comparisons; it leaves
  visual crowds and map ambience running and has no effect outside DeveloperMode.

## Requirements and compatibility

Tested with **SPT 4.1.6 / EFT 0.16.9.5-40743**; the server declares `~4.1.5`. Both client and server
components are required. An installed **Escape from Tarkov: Arena** is required on the machines
loading/registering the maps. Encrypted bundle keys target Arena **0.6.1.0.48206** and were also verified
with **0.6.0.0.47752**. An Arena update that changes the sampled map resources needs updated keys.
This requirement is not copy protection; art, audio and supporting data beside the bundles stay plaintext.

ArenaMode supplies match rules and respawns separately. DynamicMaps (tested with 1.2.1) and SAIN are optional.
Fika compatibility has not been verified. No loot or scav raids are included.

## Download and installation

Download **all five ZIP parts** and the checksum file from the GitHub release assets:

| File | Contents |
|---|---|
| `maschine-ArenaMapPort-0.4.0-part1of5-core.zip` | Client and server DLLs, shared spectator textures/calls, common artwork and installation notes |
| `maschine-ArenaMapPort-0.4.0-part2of5-equator.zip` | Equator map files |
| `maschine-ArenaMapPort-0.4.0-part3of5-bay5.zip` | Bay5 map files |
| `maschine-ArenaMapPort-0.4.0-part4of5-airpit.zip` | Air Pit map files |
| `maschine-ArenaMapPort-0.4.0-part5of5-bowl.zip` | Bowl map files |
| `maschine-ArenaMapPort-0.4.0.sha256` | SHA-256 checksum of every ZIP part |

Close EFT and the SPT server. Extract **every ZIP part separately into the same SPT root**, merging
`BepInEx` and `SPT_Runtime`, then restart the server and game. Extraction order does not matter;
the parts are ordinary ZIPs and must not be concatenated. GitHub's automatic source-code archives
do not include the maps. Install all parts from this release; a DLL-only update is insufficient.

Upgrading the published 0.3.0 package needs no spectator cleanup because that release contained none.
Development installations with earlier per-map PNGs can retain those unused copies safely, but they
consume extra space. After installing and verifying all five parts, remove only the `.png` files directly
inside `BepInEx/plugins/maschine-ArenaMapPort/spectators/arena_airpit`, `arena_equator`, `arena_bay5`
and `arena_bowl`. Keep each `spectator.json.gz` and the complete `spectators/shared` folder. The development
deployment script provides `-RemoveLegacySpectatorTextures` (dry run first, then `-Confirm`); it refuses
unknown/changed files or incomplete replacements. Keep your configuration files.

## Verification and known limitations

The [29 October native sweep](https://github.com/maschine34675/ArenaMapPort/blob/v0.4.0/docs/progress/release-sweep-20261029.md) exercised all four maps on GPU-2,
including Equator day/night, animated crowds, bot combat/objectives, native match ends and resource cleanup.
The final Bowl rerun passed after the late physics-sound fix. The source suite passed 2,545 tests and
the client Release build had zero warnings/errors. These are bounded checks of the swept client;
they do not certify subjective audio quality or the hashes of a later release rebuild.

- Intermittent short noise reported on Equator remains unresolved. It persisted in a reverb-disabled
  comparison, while a later Air Pit round using the same clips had no noticed burst. This is not a
  confirmed SurroundAudio incompatibility, and no noise fix is claimed.
- The native Books impact-sound bank is missing; those prop impacts remain silent.
- Spectator output peaks are a developer diagnostic. A zero peak with DeveloperMode off means the
  diagnostic did not run, not that playback was silent. The spectator-call switch can support a
  controlled hearing comparison without changing clips, filters or gains.

The October 28 single-ZIP candidate is obsolete and is not an asset of this release. Its historical
checks and hashes remain in [HANDOFF.md](https://github.com/maschine34675/ArenaMapPort/blob/v0.4.0/HANDOFF.md)
and the append-only progress records.
