# ArenaMapPort 0.2.2

Brings **Air Pit**, **Equator (Day/Night)** and **Bay5** from Escape from Tarkov: Arena to SPT.
This is the version intended for the Forge. 0.2.1 (GitHub and Pixeldrain only) is superseded: 0.2.2
adds the spawn gates for mode plugins, Air Pit's original north team box and a renamed Equator file.

## Included

- **Air Pit:** an abandoned terminal hangar from Arena. It contains the furnished main hall
  with its four shops, the passport hall and the apron. Like Bay5 it has two normal server-time
  choices, a progressing day/night cycle and dynamic weather. Bot spawns, waves and PMC squads
  are included, and two gates (Air Pit North Gate and Air Pit South Gate) serve as extractions.
- **Equator** with a realistic daytime appearance and an optional neon midnight appearance.
- **Bay5** with normal time progression and dynamic weather.
- Imported geometry, materials, lighting, audio, collision and navigation, plus
  map-specific repairs.
- Optional DynamicMaps overview maps for all three maps, stored inside ArenaMapPort's own
  directory. Air Pit shows its ground floor; its upper spectator area is omitted.
- Original map descriptions in English, German and Russian, with English fallback.
- Per-room gunshot reverb on all three maps: shots ring differently in a big hall than in a
  small shop. The room data is invented, because neither EFT nor Arena provides gunshot
  reverb values; outdoors the shipped acoustics stay. It can be switched off per map under
  `Audio (<map key>)` / `RoomShotAcoustics` with `General/DeveloperMode` enabled (enable it
  and restart EFT).
- Spawn gates for mode plugins (see below).

The maps are intended for **ArenaMode**, which is installed separately. No loot or scav raids
are provided. Tested with **SPT 4.1.6 / EFT 0.16.9.5-40743**; server compatibility is `~4.1.5`.
Optional DynamicMaps integration was tested with 1.2.1.

## Changes since 0.2.1

- **Spawn gates for mode plugins.** A mode plugin (ArenaMode) can keep the team spawn enclosures
  closed through its preparation phase and open them when the fight starts, as Arena does:
  Equator's booth doors slide into their frames, Bay5's warehouse and depot gates and Air Pit's
  bus doors switch off. While closed, the enclosures are sealed for bots as well, so bots inside
  a box stay inside until the release. Without a mode plugin nothing changes: the gates open at
  raid start as before. A hold that nobody releases opens after five minutes with a warning.
- **Air Pit: the original north team box.** The passport hall's north spawn pocket is part of
  the navigation again (the bake reaches the facade), and the 16 passport-control turnstiles are
  a held gate: closed in every raid, sealed for bots, opened only by a mode plugin's release
  (together with the red lane lights). In an ordinary raid the closed passport control stays
  the north limit, as in 0.2.1. The bus doors of the south box remain the gate a mode plugin may
  hold; shop shutters, portal gates and the blockout panels open at raid start as before.
- **Equator's shader file renamed** to `material-shaders.arena_equator.json`, the same rule as
  the other maps. The old `material-shaders.json` of an existing installation is unused and can
  be deleted.
- **Distribution.** Air Pit's scenes and navigation bundles are rebuilt, so upgrading from 0.2.1
  needs the full ZIP (no DLL-only package this time).

## Download

The package is built (`maschine-ArenaMapPort-0.2.2.zip` with its `.sha256` file, see below); the
Pixeldrain upload, the VirusTotal scan of the two DLLs and the GitHub release follow.

## Installation

1. Close EFT and the SPT server.
2. Extract `maschine-ArenaMapPort-0.2.2.zip` into your SPT installation, merging `BepInEx`
   and `SPT_Runtime`. Install both the client and server components.
3. Start the SPT server, then EFT.

The client folder is `BepInEx/plugins/maschine-ArenaMapPort`.
The server folder remains `SPT_Runtime/user/mods/ArenaMapPort`.

**Upgrading from 0.2.1 or 0.2.0:** with EFT and the SPT server closed, extract the ZIP over the
installation (Air Pit's bundles changed, so the two DLLs alone are not enough). The old
`BepInEx/plugins/maschine-ArenaMapPort/material-shaders.json` may be deleted. Keep `BepInEx/config`.

**Upgrading from 0.1.0:** with EFT and the SPT server closed, extract the ZIP over the
installation. Keep `BepInEx/config`; the configuration migrations run automatically.

**Upgrading a development build:** move the old `BepInEx/plugins/ArenaMapPort` directory
outside `BepInEx/plugins` before extracting. Keep your `BepInEx/config` settings.
Remove the retired `maschine-ArenaMapDebug.dll` if present, either directly in `plugins`
or inside `plugins/ArenaMapDebug`. The included README covers old database/DynamicMaps cleanup.

F12 exposes `NaturalEquatorNight` to use the natural appearance in the next Equator night raid.
`DeveloperMode` is an advanced setting and is off by default.
