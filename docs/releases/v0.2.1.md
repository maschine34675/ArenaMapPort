# ArenaMapPort 0.2.1

Fixes the blurred image inside magnifying optics on all three maps. Everything else is 0.2.0:
**Air Pit**, **Equator (Day/Night)** and **Bay5** for SPT, unchanged bundles and server data.

## Changes since 0.2.0

- **Sharp sight picture inside optics.** Through a magnifying optic (ELCAN, ACOG, riflescopes)
  the image on the ported maps was blurred like the periphery. Every vanilla map carries a small
  scene object (EFT's `ScopeMaskRenderer`) that marks the lens for the aiming depth-of-field; Arena's
  scenes have none, so the mask was never written. The mod now provides that object on its own
  maps for the duration of the raid, exactly like vanilla. Collimator sights use the same mask.
  Nothing else changed: no bundle, no server data, no configuration default. The new key
  `Camera/EnableScopeMaskFix` (default on) is visible with `General/DeveloperMode`.

## Included

Identical to 0.2.0: the three maps with imported geometry, materials, lighting, audio, collision
and navigation, map-specific repairs, bot spawns, waves, PMC squads and extractions, optional
DynamicMaps overview maps, original map descriptions (EN/DE/RU), and per-room gunshot reverb.
The maps are intended for **ArenaMode**, which is installed separately. No loot or scav raids
are provided. Tested with **SPT 4.1.6 / EFT 0.16.9.5-40743**; server compatibility is `~4.1.5`.

## Installation

1. Close EFT and the SPT server.
2. Extract `maschine-ArenaMapPort-0.2.1.zip` into your SPT installation, merging `BepInEx`
   and `SPT_Runtime`. Install both the client and server components.
3. Start the SPT server, then EFT.

The client folder is `BepInEx/plugins/maschine-ArenaMapPort`.
The server folder remains `SPT_Runtime/user/mods/ArenaMapPort`.

**Upgrading from 0.2.0:** only the two DLLs differ, and only the client DLL changes behavior.
Either extract the ZIP over the installation with EFT and the SPT server closed, or replace
`BepInEx/plugins/maschine-ArenaMapPort/maschine-ArenaMapPort.Client.dll` with the 0.2.1 file
(the GitHub release carries it as a separate asset); the server then still reports 0.2.0, which
is harmless. Keep `BepInEx/config`.

**Upgrading from 0.1.0 or a development build:** see the 0.2.0 notes; the same steps apply.

F12 exposes `NaturalEquatorNight` to use the natural appearance in the next Equator night raid.
`DeveloperMode` is an advanced setting and is off by default.
